# 🌴 Egypt Voyage Tours - منصة حجز الرحلات السياحية

منصة متكاملة واحترافية لحجز الرحلات السياحية بالبحر الأحمر ومصر، تدعم 4 لغات، حجز مباشر عبر واتساب، ولوحة تحكم كاملة للإدارة.

---

## 🚀 روابط التشغيل المباشرة (Localhost):

- **رابط الموقع الرئيسي:** [http://localhost:3001](http://localhost:3001)
- **لوحة تحكم الأدمن:** [http://localhost:3001/admin.html](http://localhost:3001/admin.html)
- **رمز الدخول للأدمن (Admin PIN):** `admin123`

---

## ✨ المميزات الرئيسية للمشروع:

1. **4 مدن رئيسية (Destinations):**
   - الغردقة (Hurghada)
   - شرم الشيخ (Sharm El Sheikh)
   - مرسى علم (Marsa Alam)
   - العلمين والساحل الشمالي (Alamein & North Coast)
   
2. **دعم كامل لـ 4 لغات (Multi-language):**
   - 🇬🇧 الإنجليزية (English)
   - 🇷🇺 الروسية (Русский)
   - 🇫🇷 الفرنسية (Français)
   - 🇵🇱 البولندية (Polski)
   - تحويل فوري لكل نصوص الموقع وتفاصيل الرحلات بضغطة زر واحدة.

3. **حجز سريع عبر واتساب (Instant WhatsApp Booking):**
   - رسالة ذكية ومجهزة تلقائياً بلغة السائح المختارة.
   - تشمل اسم الرحلة، المدينة، تاريخ الرحلة، عدد الأفراد البالغين والأطفال، اسم الفندق، والتكلفة التقديرية.

4. **لوحة تحكم للأدمن (Admin Dashboard):**
   - إضافة / تعديل / حذف الرحلات.
   - تعديل فوري للأسعار مباشرة من الجدول دون فتح صفحات معقدة.
   - رفع صور الرحلات من جهازك مباشرة.
   - تفعيل أو إخفاء أي رحلة بنقرة واحدة (Active / Hidden Toggle).
   - تعديل رقم الواتساب المستقبل للحجوزات وتغيير رمز الـ PIN.
   - سجل متابعة الحجوزات والعملاء المحتملين (Leads).

5. **جاهز بنسبة 100% للاستضافة على Hostinger:**
   - متوافق مع خطط Hostinger Web Hosting المشتركة.
   - يشمل ملف قاعدة بيانات MySQL جاهز للاستيراد: `database.sql`.
   - كود مهيأ لربط GitHub مع Hostinger Git Deployment.

---

## 🛠️ كيفية تشغيل المشروع محلياً في أي وقت:

```bash
npm run dev
```
سيبدأ السيرفر فوراً على المنفذ المتاح (`http://localhost:3001` أو `3000`).
